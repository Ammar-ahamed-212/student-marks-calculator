# Student Marks Calculator with Grades

A beginner-friendly Python program that calculates student marks, grades, average marks, and identifies the highest and lowest marks.

## Features

- Enter multiple subjects
- Enter marks for each subject
- Calculate total marks
- Calculate average marks
- Assign grades
- Find the highest mark
- Find the lowest mark
- Display the subjects with the highest and lowest marks

## Grade System

| Marks | Grade |
|---|---|
| 90 - 100 | A+ |
| 80 - 89 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| Below 50 | F |

- Python
